# 2. GEOLOCATION & CHRONOLOCATION (SHADOW & MAP ANALYSIS)
# Finding the exact coordinates and time an image or video was captured.
# ==============================================================================

# 1. EXIF Metadata Geotag Extraction:
exiftool -GPSLatitude -GPSLongitude -GPSPosition image.jpg
# If GPS coordinates are in degrees/minutes/seconds, format into decimal for Google Maps:
# Format: 14°35'28.2"N 120°58'59.1"E -> Search directly in Google Maps.

# 2. OpenStreetMap Feature Querying (Overpass Turbo):
#    Link: https://overpass-turbo.eu/
#    Query specific co-located items (e.g., church within 50m of a railway and bakery):
#    Example Overpass QL query:
#    node["amenity"="place_of_worship"](around:100, lat, lon);

# 3. Sun & Shadow Analysis (Chronolocation):
#    - SunCalc (https://www.suncalc.org/):
#      Calculates sun position, elevation, and shadow length/angle at any given location, date, and time.
#    - Shadow Ratio Formula: Shadow Length / Object Height = cotangent(Solar Elevation).

# 4. Geolocation Heuristics Checklist:
#    - License plate colors and numbering schemes (e.g. green plates, EU country identifiers).
#    - Driving side (Left-hand vs. Right-hand drive road signs and markings).
#    - Utility pole types (Concrete vs wood, stepped transformer poles in Japan/Philippines).
#    - Language, dialect, and street sign typography.
#    - Architecture, roof pitches, and local flora/vegetation.

# 4. DOMAIN, IP & INFRASTRUCTURE OSINT
# ==============================================================================

# 1. DNS Record Querying via Git Bash:
whois targetdomain.com
dig targetdomain.com ANY +noall +answer
dig targetdomain.com MX
dig targetdomain.com TXT    # Often contains SPF, verification codes, or flags!

# 2. Certificate Transparency Logs (Discover Hidden Subdomains):
# Query crt.sh for all registered SSL certificates:
curl -s "https://crt.sh/?q=%.targetdomain.com&output=json" | jq -r '.[].name_value' | sort -u

# 3. Historical Website Archives:
# - Wayback Machine: https://web.archive.org/
# - Archive.today: https://archive.is/
# Fast CLI query of all archived URLs for a target domain:
curl -s "http://web.archive.org/cdx/search/cdx?url=*.targetdomain.com/*&output=text&fl=original" | sort -u
